# E24 Development Environments Docker Project

This project is about deploying a web application with a strong focus on containerization, security, and efficiency. The application is pre-built and available as a Docker image on Docker Hub, so you can easily deploy it using the provided `docker-compose.yml` file.

## To run the app:

1. Ensure you have Docker and Docker Compose installed on your machine.
2. Clone the repository:
3. Unzip the repository in your desired location
4. In the project directory, run the following command:
```bash
docker-compose up
```
5. Once the containers start, the web app will be hosted on http://localhost:3000.
